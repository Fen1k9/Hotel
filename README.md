# Система управления отелем

Django-приложение для управления бронированием номеров, гостями и услугами отеля. Система предоставляет полный функционал для учета бронирований, гостей, номеров и дополнительных услуг.


## Начало работы

Эти инструкции предоставят вам копию проекта и помогут запустить на вашем локальном компьютере для разработки и тестирования.

### Необходимые условия

Что нужно для установки программного обеспечения и как его установить
Перед началом работы убедитесь, что в системе установлены:

- PyCharm Community Edition 
- База данных (DBeaver, используется - PostgreSQL)


*Шаг 1: Запустите PyCharm**

*Шаг 2:Создайте новый проект**

Нажмите "New Project", задайте имя проекту (например, Hotel), нажмите "Create".

*Шаг 3: Установка зависимостей**

Откройте терминал в PyCharm (View → Tool Windows → Terminal) и выполните:

- pip install django-admin psycopg2-binary

*Шаг 4: Клонируйте репозиторий, сделайте:**

1. На GitHub перейдите на главную страницу репозитория.

2. Над списком файлов нажмите <> Code.

3. Скопируйте URL-адрес репозитория.

Чтобы клонировать репозиторий с использованием HTTPS, нажмите два квадратика в разделе «HTTPS» (либо скопируйте саморучно URL-адрес).

4. Откройте Terminal.

5. Измените текущий рабочий каталог на тот, в котором вы хотите разместить клонированный каталог.

6. Введите git clone, а затем вставьте URL-адрес, который вы скопировали ранее.

git clone https://github.com/Fen1k9/Hotel.git

7. Нажмите Enter, чтобы создать локальный клон

**Шаг 5: Настройка базы данных и миграций**

Выполните в терминале команды для создания структуры БД:

- python manage.py makemigrations 
- python manage.py migrate

**Шаг 6: Запуск сервера разработки**

- python manage.py runserver

**Шаг 7: Перейдите по ссылке из данной строки**

Starting development server at http://127.0.0.1:8000/
